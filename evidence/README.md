# Evidence Folder

This directory stores raw evidence, photos, network logs, and test results:

- `photos/`: Photos of indoor unit rating label, outdoor unit rating label, remote controller, and Wi-Fi dongle/module.
- `screenshots/`: Screenshots of the official manufacturer app (controls, settings, device info).
- `network/`: Network captures, mDNS/SSDP scans, probe logs, or packet inspection (sanitized of sensitive tokens/passwords).
- `test_results/`: Hardware test execution logs and verification evidence.
